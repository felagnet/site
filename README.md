# felag.net

The Felag website: one page, generated by a small Python script and served by GitHub Pages at https://felag.net.

## Build

```
python3 build_site.py
python3 make_dist.py
```

`build_site.py` writes `out/felag-rune.html`, which is the site, and `out/felag-harvest.html`, a kept prototype that is not deployed. `make_dist.py` assembles `dist/`, the folder Pages serves: the rune page as `index.html` with `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`, `favicon.svg`, `apple-touch-icon.png`, `og.png` and `404.html`. Both need only Python 3.10 or later and its standard library.

## Check

```
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt && python -m playwright install chromium
python3 check.py
```

`check.py` runs on `dist/` and prints a table of checks: the wording rules, the hero line and the statement, the calls to action, the portraits and People links, the head tags, the files in `dist/`, a browser pass at three window sizes and with reduced motion, and every external link. It exits non-zero on any failure. `--no-browser` and `--no-links` skip the slower parts for a quick run.

## Copy

All copy lives in the data constants at the top of `felagsite.py` (STATEMENT, CAPS, PROOF_CARDS, WALL, ERAS, OFFERS, HOW, PEOPLE, FAQ, THEMES), the hero line and sub-line in `build_site.py`, and the page chrome in `shared.py`. The master facts live in the felag-core files and in Notion, and the site follows them: change a fact there first, then here.

## Images

`og.png` and `apple-touch-icon.png` are drawn once by `python3 make_images.py` with Playwright and kept in `static/`. Run it again when the mark, the lockup or the hero line changes. `favicon.svg` and `404.html` are written by `make_dist.py` from the mark and the lockup in code.

## Deploy

Every push to `main` runs `.github/workflows/pages.yml`: build, dist, check, then deploy to GitHub Pages. A failed check stops the deploy.
